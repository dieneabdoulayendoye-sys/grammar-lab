# Grammar Lab

Grammar Lab is a lightweight, responsive English grammar learning app that runs as a single static page.

## Features

- Six guided lessons from parts of speech to modal verbs
- Searchable lessons with foundation, core and advanced filters
- Instant-feedback practice quiz with explanations
- Tap-to-reveal flashcards
- Local progress, accuracy and streak tracking
- Curated links to EnglishClub, Purdue OWL, British Council, Cambridge Dictionary and Perfect English Grammar

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages

Enable **Settings -> Pages -> Deploy from a branch**, select `main` and `/ (root)`.
